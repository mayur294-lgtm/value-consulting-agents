Section 01

What this is

Cortex now strips client names, stakeholder names, emails and account numbers out of client documents before they reach Claude — and puts the real names back when a deliverable is produced.

The detection engine needs a specific version of Python and a language model that has to be downloaded. That is the entire reason there is a setup step at all.

What it used to cover

Three markdown files. When we measured the old gate against what is actually in engagement input folders, it reached 3 of 77 files. The annual reports, RFPs, client decks and pricing spreadsheets — almost everything we really work from — went through unscrubbed.

What it covers now

Every text-bearing document in an engagement's inputs/: PDF, Word, PowerPoint, Excel, CSV. Each is converted to text and scrubbed before anything reaches the model. Names are found by a real named-entity engine rather than five hand-written patterns.

Until you run the setup, files in an engagement's inputs/ will not open. That is deliberate — opening one before the scrubber exists would send the client's real details through unchanged. Everything else in Cortex keeps working in the meantime.

Section 02

The three steps

Run these from the top of your Cortex folder, not from inside a subfolder.

Do this once
1

Get the latest Cortex

git checkout main && git pull

Everything below assumes you are on an up-to-date main.

2

Run the setup

bash scripts/setup_pii.sh

It downloads a language model of about 380 MB, so give it a few minutes. It is safe to run again at any time — a second run skips whatever is already done.

3

Check it worked

The last thing it prints is:

=== Setup complete ===

If you saw that, you are finished. Close the terminal and carry on.

Section 03

If it stops with an error

Two of these are common. The third is the catch-all.

What it saysWhat it meansWhat to do
No compatible Python found The Python that ships with macOS is 3.9, and this needs 3.10 or newer. The script deliberately does not install one for you — that is a change to your machine it should not make on its own. brew install python@3.11
then run step 2 again. Everything after that is automatic.
tesseract not found A note, not a failure. Tesseract reads text out of screenshots. Documents — PDF, Word, Excel, PowerPoint — are all protected and readable without it. Only if you work from screenshots:
brew install tesseract
Anything else Rare, and usually specific to one machine. Ask Claude directly: “help me set up PII protection”. It can read the error and tell you what it means.
Section 04

What changes day to day

Three things you will actually notice. None of them need any action.

Engagement folders look odd

They are random IDs now, not client names. The folder name is sent to Claude on every single call, so a folder named after the client identified them however well the documents inside were cleaned.

First read of a file is slower

A PDF or spreadsheet gets converted and scrubbed the first time it is opened. A few seconds. After that it is cached.

Claude tells you if it is missing

Every session start checks. Set up correctly, you see nothing at all. Not set up, you get the one command that fixes it. It never blocks you.

Finding an engagement now the folders are IDs

You never need to know or type an ID.

./scripts/find_engagement.sh navy_federal

Partial and case-insensitive, so half-remembered spellings work. The ID is linked to the client only in a file on your own machine, which is never committed and never sent anywhere.

If you have folders from before this change

Convert them once:

./scripts/migrate_engagement_ids.sh

That command only shows you the plan — it moves nothing. When the plan looks right, run it again with --apply on the end, and it will ask you to confirm before touching anything.

Section 05

What it does not do

Worth being clear about the edges, so you know where your own judgement still has to do the work.

It is not a substitute for judgement

It catches names, contact details, identifiers and financial account numbers. It does not know that a particular sentence describes a confidential restructuring.

It works in English

Non-English documents get pattern-based protection — emails, numbers, the client's own name — but not full name detection. Flag it if you are working in another language.

It does not cover pasted text

The gate sits on files in inputs/. If you paste a transcript into a message it goes through as typed. Put client material in inputs/ and point Claude at it.
