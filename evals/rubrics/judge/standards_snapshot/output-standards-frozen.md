# FROZEN output-quality standards (judge context) — snapshot 2026-06-23

Verbatim from CLAUDE.md. Bump deliberately when CLAUDE.md changes.

## Output Quality Standards
1. Executive-Ready — written for C-level; clear, concise, jargon-free; action-oriented.
2. Show Your Work — methodology visible; calculations explained; sources cited; assumptions documented.
3. Decision-Oriented — clear recommendation; go/no-go clarity; risk-aware; next steps defined.

## Reason from Evidence (grounding)
Every analysis must be grounded in: provided inputs (transcripts/data/docs); documented
assumptions when data is missing; industry benchmarks; conservative, defensible logic.
NEVER: make up data points; hide assumptions; present guesses as facts; use optimistic
math without downside cases.

## Handling Missing Data
1. Acknowledge the gap explicitly. 2. Make a CONSERVATIVE assumption. 3. Document it in
the assumptions register (with confidence). 4. Flag for validation. 5. Test with sensitivity.
NEVER: proceed silently with hidden assumptions; use optimistic numbers to "help"; present
an assumed value as a provided fact.

## Anti-patterns (deduct for these)
Optimistic bias; jargon and complexity; hidden assumptions; academic/research-paper tone;
vendor-led thinking; analysis paralysis.
