Tools • Skills • Agents

Complete System Architecture & How They Work Together

Tools — Low-level utilities
Skills — User-triggered commands
Agents — Autonomous reasoning entities
Knowledge — Domain data & templates
🔧
Tools
Low-Level Utilities
What: Basic building blocks that perform specific operations.
How: Called programmatically by Claude or agents.
When: Automatically during task execution.
📖 Read
Read files from filesystem (code, PDFs, images, notebooks)
← file path → file content
✏️ Write
Create new files or overwrite existing ones
← path + content → created file
🔄 Edit
Make precise string replacements in files
← old + new string → modified file
💻 Bash
Execute shell commands (git, npm, python, etc.)
← command → stdout/stderr
🔍 Grep
Search file contents with regex patterns
← pattern → matches
📂 Glob
Find files by name patterns (*.md, src/**/*.ts)
← pattern → file paths
🌐 WebFetch
Fetch and process web content
← URL + prompt → extracted data
🔎 WebSearch
Search the web for current information
← query → search results
📋 Task
Launch specialized sub-agents for complex work
← agent type + prompt → agent result
✅ TodoWrite
Manage task lists for tracking progress
← todo items → updated list
⚡
Skills
User-Triggered Commands
What: Pre-defined workflows triggered by /command.
How: User types slash command in chat.
When: On-demand when user needs specific capability.
/presentation
Generate Prezi-style interactive HTML presentations from any content
user invoked → HTML file
/generate-roi-excel
Create professional Excel ROI models ([Client-wealth-APAC-2025]/Seabank format)
user invoked → .xlsx file
/chunk-document
Split large PDFs/CSVs into processable chunks
user invoked → chunked data
/domain-context
Load complete domain knowledge pack (retail, sme, wealth, etc.)
user invoked → domain data
/domain-benchmarks
Query Consulting Playbook benchmarks by domain/journey
user invoked → benchmark table
/domain-pain-points
Retrieve common pain points for discovery preparation
user invoked → pain point list
/domain-journeys
Access customer/operational journey maps
user invoked → journey maps
/domain-usecases
Query Backbase use cases & capabilities by category
user invoked → use case list
/domain-value-props
Get value propositions & differentiation themes
user invoked → value props
🤖
Agents
Autonomous Reasoning Entities
What: Specialized AI personas with methodologies & standards.
How: Orchestrator routes work; agents reason & produce artifacts.
When: Automatically based on engagement type.
🎯 Orchestrator
Central coordinator — classifies engagements, routes to agents, enforces quality gates
← user request → delegations
🔍 Discovery Agent
Extracts evidence, pain points, metrics, constraints from raw inputs
← transcripts/notes → evidence registers
📊 Capability Agent
Assesses maturity (1-5), identifies gaps, prioritizes improvements
← evidence + domain → gap analysis
💰 ROI Agent
Builds financial models with 3 scenarios, sensitivity analysis, assumptions
← evidence + benchmarks → Excel model
📈 Benchmark Librarian
Curates benchmarks with confidence ratings, regional specificity
← domain/region/metric → rated benchmarks
🗺️ Roadmap Agent
Sequences initiatives by value, feasibility, dependencies
← gaps + ROI levers → phased roadmap
📦 Assembly Agent
Packages all outputs into executive-ready deliverables
← all agent outputs → final deliverables
📊 Side-by-Side Comparison
Aspect 🔧 Tools ⚡ Skills 🤖 Agents

Triggered By Claude/Agents automatically User via /command Orchestrator or Task tool
Complexity Single operation Multi-step workflow Full reasoning + methodology
State Stateless Stateless Maintains context, references others
Output Raw data / file changes Formatted results / files Complete consulting artifacts
Uses Tools? — Yes (internally) Yes (Read, Write, Grep, etc.)
Uses Skills? No — Can invoke via Skill tool

🔗 Key Relationships
🔧 → 🤖
Tools Enable Agents
Agents use tools to read files, search code, write outputs, and execute commands.
Example:
Discovery Agent uses Read to load transcript → uses Write to save evidence register
⚡ → 🔧
Skills Use Tools
Skills internally call tools to accomplish their workflows.
Example:
/domain-benchmarks uses Read to load CSV → Grep to filter → returns formatted table
🤖 → 🤖
Agents Collaborate
Orchestrator delegates to agents. Agents pass artifacts downstream.
Example:
Discovery → Capability → ROI → Roadmap → Assembly (pipeline)
📚 → 🤖
Knowledge Feeds Agents
Agents read domain packs, benchmarks, and templates to ground their work.
Example:
ROI Agent reads knowledge/domains/wealth/benchmarks.md to get industry metrics
👤 → ⚡
User Triggers Skills
Users invoke skills directly via slash commands for specific capabilities.
Example:
User types /presentation → Gets interactive HTML presentation
🤖 → ⚡
Agents Can Invoke Skills
Agents can call the Skill tool to leverage pre-built workflows.
Example:
ROI Agent invokes /generate-roi-excel to produce final spreadsheet

✨ Summary

Tools are the hands — they perform atomic operations (read, write, search, execute).

Skills are the shortcuts — user-triggered workflows that combine tools for specific tasks.

Agents are the consultants — they reason, apply methodology, and generate deliverables.

Together, they form a complete consulting automation system that transforms raw inputs into executive-ready deliverables.
